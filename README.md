# 🚀 Next.js 15 + Apollo Client + graphql-let Boilerplate

A modern, scalable boilerplate for building high-performance React apps with **Next.js 15**, **Apollo Client**, **GraphQL**, and **graphql-let** for automatic TypeScript types generation.

---

## 📦 Stack

- **Next.js 15** (App Router)
- **Apollo Client v3**
- **graphql-let** (Typed GraphQL via codegen)
- **GraphQL Code Generator**
- **Tailwind CSS v4**
- **next-intl** (Internationalization)
- **TypeScript** (strict mode)
- **Jotai** (state management)
- **eslint** + **typescript-eslint**
- Deployment-ready config with flexibility for production/staging environments

---

## 🛠️ Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/your-username/next15-gql-app.git
cd next15-gql-app
pnpm install
```

### 2. Set up environment

Create a `.env` file:

```bash
cp .env.example .env
```

Edit it to match your GraphQL backend:

```env
FRAMEWORK_PROVIDER=graphql
NEXT_PUBLIC_GRAPHQL_API_ENDPOINT=http://localhost:4000/graphql
```

### 3. Codegen GraphQL types

```bash
pnpm codegen
```

This uses `graphql-let` to auto-generate types for your queries and mutations.

### 4. Run the development server

```bash
pnpm dev
```

## ⚙️ Code Generation

Uses `graphql-let` with `@graphql-codegen` presets:

```bash
pnpm codegen
```

Configuration in `.graphql-let.yml`:

```yaml
schema: http://localhost:4000/graphql
documents: ./graphql/**/*.graphql
plugins:
  - typescript-operations
  - typescript-react-apollo
cacheDir: __generated__
```

## 🚀 Build for Production

```bash
pnpm build

```

Set `APPLICATION_MODE=production` to skip type and lint errors during build if necessary.
